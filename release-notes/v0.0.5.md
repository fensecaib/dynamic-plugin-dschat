# dynamic-bot-agent v0.0.5

## 宿主兼容性修复

- 插件 API 声明升级为 `3.0.0`，core 编译依赖升级为 `0.0.4`，修复 API 3 宿主拒绝加载插件的问题。
- 本版本面向插件 API 3.x 的宿主；API 2.x / 4.x 宿主需要对应版本的插件。

## Dota2 查询与显示

- 所有 Dota2 查询均需先绑定账号，包括指定玩家查询；绑定和帮助无需绑定。
- `/dota 战报 <玩家ID> [序号]` 支持省略序号查询最新一场，单参数大于 10 时按玩家 ID 处理。
- 按比赛 ID 查询改为 `/dota 战报 比赛 <比赛ID>`，查询绑定账号参与的比赛；深度战报使用相同参数规则。
- 同步更新帮助和历史卡片提示，修复个人详情中的转义换行及分段显示。

## 安装与验证

- 下载 `dynamic-bot-agent-0.0.5-all.jar`，替换宿主 `plugins/` 目录中的旧插件后重启，不要同时保留多个版本。
- 附带 SHA-256 校验文件。
- 本地 `gradlew test fatJar` 已通过，并核验 JAR 的 API 声明及未打包宿主 core 类；尚未在实际运行宿主中实测。
