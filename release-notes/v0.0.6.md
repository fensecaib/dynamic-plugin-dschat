# dynamic-bot-agent v0.0.6

## OpenDota 故障提示

- 绑定、历史、战报、双阵营分析和个人详情查询失败时，明确显示 OpenDota 故障原因，不再把服务异常误报为玩家或对局不存在。
- 区分 HTTP 522 回源连接超时、524 响应超时、5xx 服务端异常、429 限流及 401/403 访问拒绝。
- 网络连接或请求超时单独提示检查网络及稍后重试，不直接断言 OpenDota 全站故障。
- 校验 HTTP 200 响应中的错误对象、异常字段类型及比赛 ID；响应异常时提示数据格式错误。正常空记录和 404 保留无数据处理。
- 命令与聊天入口统一错误文案，不输出原始错误响应；取消请求保持取消语义，失败或取消后释放报告任务名额。

## 兼容与安装

- 继续使用插件 API `3.0.0`，编译依赖 `dynamic-bot-core:0.0.4`。
- 下载 `dynamic-bot-agent-0.0.6-all.jar`，替换宿主 `plugins/` 中旧版本后重启，不要同时保留多个版本。
- 附带 SHA-256 校验文件；故障处理通过本地模拟接口测试，完整测试和打包由 CI 再次验证。
