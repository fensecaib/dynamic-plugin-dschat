## 新增与优化

- 个人详情升级为最近十场报告：统一统计、英雄分布、基准雷达、逐场趋势、四维分析和代表对局，采用深色卡片布局。
- 普通与深度个人详情直接复用战报锐评风格；正文按完整句子控制篇幅，保留段末金句。
- 支持 `/dota 历史 [玩家ID]`、`/dota 战报 <玩家ID> <序号>`、`/dota 个人详情 [玩家ID]`；深度战报同样支持指定玩家。指定玩家查询无需绑定、不修改绑定。
- 精简 Dota 指令帮助、历史查询提示、进度和忙碌提示，README 同步更新。`<参数>` 必填，`[参数]` 可选，括号不用输入。
- 为兼容原有比赛 ID 查询，指定玩家的战报必须带 1～10 序号；1 为最新一场。单参数大于 10 仍按比赛 ID 处理。

## 修复与可靠性

- 修复小数校验误判、昵称清洗和未指定 JSON 输出格式时的接口兼容问题。
- 修正请求失败时保留已经通过检查的分析段落；截断响应不进入报告，无效章节显示数据摘要。
- 统一两个入口的比赛 ID、目标玩家、阵营和胜负校验；支持从 `player_slot` 补全阵营，缺失或冲突时明确报错。
- 最近十场详情限制并发并缓存成功结果；战报与个人详情共用任务名额，忙碌时不排队。

## 验证与安装

- 本地 35 项测试通过，`test fatJar` 构建成功。
- 下载 `dynamic-bot-agent-0.0.4-all.jar`，替换宿主 `plugins/` 中的旧版本后重启；不要同时保留两个版本。附带 SHA-256 校验文件。
- AI 规则检查不等于完整事实审核，锐评仍可能包含未经数据支持的推断。
