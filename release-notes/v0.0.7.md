# dynamic-bot-agent v0.0.7

- 可在宿主配置中分别开启或暂停 AI 对话、命令与 @Bot 触发，以及 Dota2 绑定、历史和分析功能。
- DeepSeek 默认模型更新为 `deepseek-flash`，支持配置请求超时和重试；未配置或服务故障时明确提示分析不可用。
- 绘图产物默认保留 72 小时，可在宿主调整；自动清理不会删除图标、头像和字体缓存。
- 新增 `/dota绑定`、`/dota历史`、`/dota战报`、`/dota深报`、`/dota分析`、`/dota详情`、`/dota深详`、`/dota帮助`，保留原有指令。
- 改善 QQ 官方渠道的图片回复；历史查询不再额外发送指令提示。
- 增加流程日志，改善对话排版，并修复并发、取消和资源释放问题。

适用于插件 API 3.x 宿主。下载 [插件 JAR](https://github.com/fensecaib/dynamic-plugin-dschat/releases/download/v0.0.7/dynamic-bot-agent-0.0.7-all.jar) 和 [SHA-256 校验文件](https://github.com/fensecaib/dynamic-plugin-dschat/releases/download/v0.0.7/dynamic-bot-agent-0.0.7-all.jar.sha256)，替换旧包并重启宿主。
